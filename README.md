## Featured Project

### Refugee Population Forecasting & Humanitarian Resource Planning System, Kenya
*Moringa School capstone, team of 7*

A forecasting project to help humanitarian planners anticipate refugee population trends in Kenya.

- Cleaned and engineered a **25-year, 27,664-record dataset** from HDX HAPI. This meant resolving aggregated categories, validating extreme values, and preparing the data for time-series modelling.
- Ran exploratory analysis to surface demographic and temporal patterns, then turned the findings into **resource-planning recommendations**.
- Built a **Linear Regression baseline** and benchmarked it against a **custom Transformer model in PyTorch**, evaluated with **MAE, RMSE, and R²**.
